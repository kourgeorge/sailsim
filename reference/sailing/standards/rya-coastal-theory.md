## Original summary

This shorebased course builds on Day Skipper-level knowledge and lists 40 hours plus exam time. Its public topic list includes position fixing, shaping and plotting courses, tidal knowledge, almanacs and navigation publications, electronic position finding, forecast interpretation and weather-system/barometer use. It is useful evidence for increasing decision complexity. Requirements for a particular practical exam should be checked on that exam’s own page rather than inferred from marketing copy.

## Proposed learning outcomes

- Cross-check position using independent information.
- Account for tidal height and current when timing a passage.
- Define forecast triggers that change a route or departure decision.

## Application and limits

Primary planning source for sail-37–42; actual charts, local data and supervised navigation exercises remain necessary.
