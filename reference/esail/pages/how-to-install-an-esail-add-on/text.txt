How to install an eSail Add-On

Thank you for purchasing an eSail Add-On! You should have received an email with your licence key for the add-on / DLC (downloadable content). Please allow a few minutes after purchase for the email to arrive and check your junk folder if you cannot find it.

NOTE: Installed add-ons can be found inside eSail once launched. They are not seen as separate ‘games’ in your Steam library.

1. Start Steam

Open your Steam client with your Account Name and Password.

2. Activate the software using your eSail licence key

Your licence key (Product Code) has been sent to you by email. Click on ADD A GAME, bottom left, then ‘Activate a product on Steam’. Follow the instructions to activate eSail. (Note: this button is inside the Steam Software you downloaded NOT on the Steam web page.)

3. Start eSail

After successful code verification go to the Library/Games and Start eSail. Make sure that the Add-On has downloaded by checking the eSail version on the Splash Screen which should now show the Add-On name.

Information on your add-on can be found in the Quick Start / Advanced Tutorials section.

eSail is available for Windows and Apple Mac.
