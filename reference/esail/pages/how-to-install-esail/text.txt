How to install eSail

Thank you for purchasing eSail! You should now receive an email with your license key. Please allow a few minutes after purchase for the email to arrive and check your junk folder if you cannot find it.

eSail is downloaded and managed using Steam. Contact

Support

if you have any problems with installing or signing up to Steam.

1. Get the Steam software client

Go to the

Steam About page

and install the Steam software.

2. Start Steam

After installing Steam, you should see an icon on your desktop. Double click it.

From the login screen click the button

CREATE A NEW ACCOUNT…

.

Follow the instructions to create an account.

NOTE: Your account name must not contain any spaces.

You may be asked for a Steam Guard code during the process. This is a code generated by Steam and sent to you by email. Do not confuse this with the license key you are sent by eSail. If you do not receive it please check your email junk folder.

IMPORTANT: If you have difficulties with the CAPTCHA please see

Installation Technical Support Guide

or contact

Support

.

3. Activate eSail by using your eSail license key

Start the Steam Software on your computer. Click on ADD A GAME, (bottom left of the Steam software screen), then ‘Activate a product on Steam’. Follow the instructions to activate eSail. Your license key (Product Code) has been sent to you by email. Make sure you add any add-ons you have purchased in the same way.

NOTE: If you have purchased add-ons, activate the main eSail Sailing Simulator license key first. Once installed, any add-ons can be found inside eSail when launched. They are not seen as separate ‘games’ in your Steam library.

4. Download eSail

After successful code verification go to the Library/Games section in your Steam software and install eSail. Information on any add-ons can be found in the Quick Start / Advanced Tutorials section.

eSail is available for Windows and Apple Mac.
